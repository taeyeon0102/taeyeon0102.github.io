> ## 4장 핵심 내용
> 훈련 데이터로부터 가중치 매개변수의 최적값을 자동으로 찾아내는 과정을 다룬다.
> 신경망이 **손실 함수**라는 지표를 기준으로, **기울기**를 사용하여 매개변수를 조금씩 업데이트하는 **경사하강법**의 원리와 구현 방법을 핵심적으로 다룬다.


# 1. 학습 (Learning)

## 학습의 정의와 필요성

**학습**: 훈련 데이터로부터 **가중치 매개변수의 최적값**을 자동으로 찾아내는 과정

**수동 설정의 한계**: 2장의 퍼셉트론처럼 사람이 직접 매개변수를 정하는 것은 수천, 수억 개의 매개변수를 가진 현대의 신경망에서는 불가능하다.

## 데이터 주도 학습 (Data-Driven Learning)

**패턴 발견:** 기계학습은 사람이 규칙을 만드는 대신, 데이터 속에 숨겨진 **패턴**을 기계가 스스로 발견하도록 한다.

**사람의 개입 최소화:** 데이터 중심의 접근 방식을 통해 문제 해결 시 사람의 개입과 직관에 따른 시행착오를 줄일 수 있다.

## 종단간 기계학습 (End-to-End Machine Learning)

**전통적 방식 :** 사람이 SIFT, HOG와 같은 **특징(feature)**을 직접 설계하고, 이를 바탕으로 SVM, KNN 등 기계학습 알고리즘을 적용한다.

**신경망 방식 :** 이미지 등에 포함된 중요한 특징까지도 **기계가 스스로 학습**합니다. 처음부터 끝까지 사람의 개입 없이 결과물(출력)을 얻는다는 의미에서 **종단간 기계학습**이라고 부른다.

## 훈련 데이터와 시험 데이터

**범용 능력(Generalization):** 아직 보지 못한 데이터(훈련 데이터에 포함되지 않은 데이터)로도 문제를 올바르게 풀어내는 능력이다.

**데이터 분리:** 모델의 범용 능력을 제대로 평가하기 위해 데이터를 **훈련 데이터(training data)** 와 **시험 데이터(test data)** 로 나누어 사용합니다.

**오버피팅(Overfitting):** 특정 데이터셋(훈련 데이터)에만 지나치게 최적화되어, 다른 데이터셋에서는 제대로 된 성능을 내지 못하는 상태를 말하며, 이를 피하는 것이 기계학습에서 중요하다.

# 2. 손실 함수 (Loss function)

## 손실 함수의 정의와 목적

**지표:** 손실 함수는 신경망이 훈련 데이터를 얼마나 잘 처리하지 못하느냐, 즉 **'나쁨'을 나타내는 지표**.

**목표:** 이 손실 함수의 값을 **최소로 만드는 가중치 매개변수의 값**을 찾는 것이 신경망 학습의 최종 목표이다.

## 대표적인 손실 함수

- $t_k$=정답 레이블(원-핫 인코딩), $y_k$=출력값

### 오차제곱합 (SSE)
각 원소의 출력(추정 값)과 정답 레이블의 차이를 제곱하여 그 총합을 구하는 방식.
    
$$E = \frac{1}{2}\sum_k(y_t-t_k)^2$$
    
```python
def sum_squares_error(y, t):
    return 0.5 * np.sum((y - t)**2)
## 각 원소의 차이를 계산하고 제곱한 뒤 그 총합을 구함
```
> 가장 많이 쓰이는 손실 함수 중 하나로, 신경망의 출력(*y*)과 정답 레이블(*t*) 사이의 차이를 제곱하여 합한 후 0.5를 곱한다.
    
### 교차 엔트로피 오차 (CEE)
정답 레이블이 1인 경우의 출력값에 자연로그를 취한 값($−logy_k$)으로 계산한다. 정답일 때의 출력이 1에 가까울수록 오차는 0에 가까워지고, 출력이 작아질수록 오차는 커진다.
    
$$E = -\sum_k t_k \log  y_k$$
    
```python
def cross_entropy_error(y, t):
    delta = 1e-7 # 아주 작은 값
    return -np.sum(t * np.log(y + delta))
```
> 정답 레이블이 1인 경우의 출력값에 자연로그를 취한 값으로 계산한다. 코드 구현 시 **`np.log`**에 0을 입력하면 음의 무한대(**`-inf`**)가 되어 계산이 불가능해지므로, 아주 작은 값인 **`delta`**를 더해 수치적으로 안정되게 만든다.
    

## 미니배치 학습 (Mini-batch Learning)

**필요성:** 모든 데이터에 대한 손실 함수를 계산하려면 시간이 너무 오래 걸린다.(예: MNIST 데이터 60,000개).

**방법:** 데이터 중 일부(예: 100개)를 무작위로 뽑아 학습하는 방식을 **미니배치 학습**이라고 한다.

**평균 손실 함수:** 미니배치의 개별 손실 함수 합을 데이터 개수(*N*)로 나누어 **평균 손실 함수**를 구함으로써 데이터 개수와 상관없이 일관된 지표를 얻는다.

$$E = -\frac{1}{N}\sum_n \sum_k t_{nk} log y_{nk}$$

#### **미니배치 학습 구현**

- **미니배치 학습을 위한 데이터 무작위 선택**
    
    수만 개의 데이터를 한꺼번에 계산하는 대신 일부(미니배치)를 무작위로 뽑아 학습하는 방식이다. 넘파이의 **`np.random.choice()`** 함수를 사용하여 훈련 데이터에서 무작위로 인덱스를 골라낸다.
    
    ```python
    # 훈련 데이터에서 무작위로 10장만 빼내기 예시
    train_size = x_train.shape
    batch_size = 10
    batch_mask = np.random.choice(train_size, batch_size) # 무작위 인덱스 생성
    x_batch = x_train[batch_mask] # 입력 데이터 미니배치
    t_batch = t_train[batch_mask] # 정답 레이블 미니배치
    ```
    
- **배치 처리를 지원하는 교차 엔트로피 오차 구현**
    
    데이터가 하나인 경우와 배치로 묶여 입력되는 경우를 모두 처리할 수 있는 범용적인 구현.
    
    **① 정답 레이블(***t***)이 원-핫 인코딩인 경우:**
    
    ```python
    def cross_entropy_error(y, t):
        if y.ndim == 1:
            t = t.reshape(1, t.size)
            y = y.reshape(1, y.size)
    
        batch_size = y.shape
        return -np.sum(t * np.log(y + 1e-7)) / batch_size # 배치 크기로 나누어 정규화
    ```
    
    **② 정답 레이블(***t***)이 숫자 레이블인 경우:** 넘파이의 팬시 인덱싱을 활용하여 정답에 해당하는 출력값만 추출하여 효율적으로 계산한다.
    
    ```python
    def cross_entropy_error(y, t):
        if y.ndim == 1:
            t = t.reshape(1, t.size)
            y = y.reshape(1, y.size)
    
        batch_size = y.shape
        # y[np.arange(batch_size), t]는 각 데이터의 정답 레이블에 해당하는 신경망 출력을 추출함
        return -np.sum(np.log(y[np.arange(batch_size), t] + 1e-7)) / batch_size
    ```
    

## 💡 왜 '정확도'가 아닌 '손실 함수'를 사용할까?

**미분의 중요성:** 최적의 가중치를 찾을 때는 가중치 매개변수의 미분(기울기)을 계산하고, 그 값을 바탕으로 매개변수를 서서히 갱신한다.

**정확도의 한계:** 정확도는 매개변수의 미세한 변화에 거의 반응하지 않고, 반응하더라도 값이 불연속적으로 갑자기 변하기 때문에 **대부분의 장소에서 미분 값이 0이 되어** 매개변수를 갱신할 수 없게 만든다.

손실 함수는 매개변수의 값이 변함에 따라 연속적으로 변화하므로, **미분 값이 0이 되지 않아** 신경망이 올바르게 학습할 수 있는 환경을 제공한다.

# 3. 미분

## 1. 용어 정리

**미분 (Derivative):** 특정 순간의 변화량

**수치 미분 (Numerical Differentiation):** 아주 작은 차분(차이)을 이용하여 미분을 근사적으로 계산하는 방법

**중심 차분 (Central Difference):** 오차를 줄이기 위해 *x*를 중심으로 그 전후의 차이를 계산하는 방식

**편미분 (Partial Derivative):** 변수가 여러 개인 함수에서 특정 변수 하나에 초점을 맞추어 미분하는 것

**기울기 (Gradient):** 모든 변수의 편미분을 벡터로 정리한 것

## 2. 수치 미분을 사용하는 이유와 계산 과정 (흐름과 수식)

미분은 본래 한순간의 변화량을 의미하며, 수식으로는 다음과 같이 정의된다.

$$
\frac{df(x)}{dx} =\lim_{h→0} \frac{f(x+h)−f(x)}{h}
$$

이러한 미분은 수학의 공식을 이용해 정확한 도함수를 구하는 **'해석적 미분(Analytic Differentiation)'** 이 이상적이지만, 신경망처럼 구조가 복잡한 함수에서는 이를 바로 구하기 어렵기 때문에 컴퓨터를 이용해 미분 값을 근사적으로 계산해야 하는데, 이를 **수치 미분**이라고 한다.

### 수치 미분의 계산 과정과 중심 차분

1. **전방 차분의 한계:** 수식 그대로 컴퓨터에 아주 작은 $h$ 값(예: 10−50)을 대입하여 계산하려 하면 컴퓨터의 소수점 표현 한계로 인해 **반올림 오차(Rounding Error)** 가 발생하여 값이 0이 되어버리는 문제가 발생한다. 따라서 $h$를 아무리 줄이더라도 $x$ 위치에서의 진정한 접선(해석적 미분)과 ($x+h$) 위치 사이의 기울기에는 *구조적인 오차*가 존재한다.

2. **중심 차분(Central Difference) 도입:** 이러한 오차를 줄이기 위해 $x$와 $(x+h)$의 차이를 구하는 전방 차분 대신, $x$를 중심으로 그 앞뒤의 값인 $(x+h)$와 $(x−h)$ 사이의 차이를 구한다.

3. **수식 도출:** 중심 차분을 수식으로 나타내면 다음과 같이 $x$ 전후의 거리가 $2h$가 되므로 이를 $2h$로 나누어 기울기를 구한다. 이 방식을 통해 수치 미분은 진정한 미분 값에 매우 근사한 값을 얻어낼 수 있다.

$$\frac{f(x+h) - f(x-h)}{2h}$$

## 3. 편미분이 필요한 이유와 흐름

1. **다변수 함수의 등장**: 실제 신경망이나 복잡한 문제는 변수가 하나인 함수가 아니라, 여러 개의 변수(가중치 매개변수들)로 이루어진 **다변수 함수**이다.(예: $f(x_0,x_1)=x_0^2+x_1^2)$

2. **변수 별 영향력 파악**: 이처럼 변수가 여럿인 함수에 대한 미분을 **편미분**이라고 한다. 편미분은 **'어느 변수에 대한 미분이냐'**를 구별하여, 목표로 하는 특정 변수 하나에만 초점을 맞추고 다른 변수는 상수로 취급하여 고정한다.

3. **기울기(Gradient)로의 확장:** 각 가중치 매개변수들이 손실 함수에 미치는 영향을 알기 위해서는 모든 변수의 편미분을 구해야 한다. 이 모든 변수의 편미분을 벡터로 모아 정리한 것이 **기울기(Gradient)** 이다.

# 4. 기울기(gradient)

## 1. 기울기(Gradient)

다변수 함수에서 **모든 변수의 편미분을 벡터로 정리한 것**을 의미한다. 가장 중요한 특징은 **기울기가 가리키는 쪽이 각 장소에서 함수의 출력 값을 가장 크게 줄이는 방향**이라는 점이다. 즉, 함수의 값을 낮추고자 할 때 최적의 이동 방향을 제시하는 나침반 역할을 한다.

## 2. 경사 하강법(Gradient Descent)

기계학습과 신경망 학습의 목표는 **손실 함수가 최솟값이 될 때의 최적의 매개변수(가중치와 편향)를 찾는 것**.이다 하지만 매개변수 공간이 너무 복잡하여 어디가 최솟값인지 직관적으로 알기 어렵기 때문에 **기울기를 단서로 최솟값을 찾는 방법**을 사용하는데, 이를 **경사 하강법**이라고 한다.
    
$$x_0=x_0−η\frac{\partial f}{\partial x_0}$$


> 현 위치에서 기울어진 방향으로 일정 거리만큼 이동하고, 이동한 곳에서 다시 기울기를 구해 나아가는 과정을 반복하며 손실 함수의 값을 점차 줄인다.
    
**학습률 (Learning Rate)**: 위 수식의 $η$(에타)는 매개변수 값을 한 번에 얼마나 갱신할지를 정하는 지표이다. 이 값이 너무 크거나 작으면 최솟값을 찾아갈 수 없으므로 적절한 설정이 필요하다.

### 3. 인공신경망에서의 기울기 계산 (수식의 흐름)

신경망에서의 기울기는 '**가중치 매개변수에 대한 손실 함수의 기울기'**를 의미한다. 형상이 $2 \times 3$인 가중치 $W$와 손실 함수 $L$이 있다고 가정할 때, 기울기를 구하는 수식의 흐름은 다음과 같다.

1. **가중치 행렬 정의**

$$W= \begin{pmatrix} w_{11} \ w_{12} \ w_{13} \\ w_{21} \ w_{22} \ w_{23} \end{pmatrix}$$

2. **손실 함수에 대한 편미분 행렬(기울기) 도출** 
: 가중치 $W$의 각 원소를 조금씩 변경했을 때, 손실 함수 $L$이 얼마나 변화하는지를 나타내는 편미분을 구해 행렬로 묶는다.

$$\frac{∂L}{∂W} = \begin{pmatrix} \frac{∂L}{∂w_{11}} \ \frac{∂L}{∂w_{12}} \ \frac{∂L}{∂2_{13}} \\ \frac{∂L}{∂w_{21}} \ \frac{∂L}{∂w_{22}} \ \frac{∂L}{∂w_{23}} \end{pmatrix}$$

3. **형상(Shape)의 일치 확인** 
수식에서 도출된 가장 중요한 핵심은 **가중치 행렬 $W$와 그 기울기인** $\frac{∂L}{∂W}$**의 형상이 동일하다**는 점이다. 위 예시에서도 두 행렬 모두 $2×3$ 형상을 가지므로, 형상이 같기 때문에 $W=W−η \frac{\partial L}{\partial W}$ 와 같이 가중치에서 기울기를 직접 빼서 매개변수를 갱신하는 것이 가능하다.

# 5. 학습 알고리즘 설계

신경망 학습은 가중치와 편향을 훈련 데이터에 적응하도록 조정하는 과정이며, 다음 4단계의 순서로 설계된다. 이를 **확률적 경사 하강법(SGD)** 라고 한다.

### 1단계 - 미니배치 (Mini-batch)
대량의 훈련 데이터 중 일부를 무작위로 선별하여 가져온다. 이 작은 데이터 묶음(미니배치)의 손실 함수 값을 줄이는 것이 목표이다.

### 2단계 - 기울기 산출
미니배치의 손실 함수 값을 줄이기 위해 각 가중치 매개변수에 대한 **기울기(편미분 벡터)**를 구한다. 이 기울기는 손실 함수의 값을 가장 작게 하는 방향을 알려준다.

### 3단계 - 매개변수 갱신
구해진 기울기 방향을 단서로 하여, 가중치 매개변수 값을 학습률(Learning Rate)에 따라 아주 조금씩 갱신한다.

### 4단계 - 반복
위의 1~3단계를 설정한 횟수만큼 지속적으로 반복하여 점진적으로 최적의 매개변수(최솟값)를 찾는다.
