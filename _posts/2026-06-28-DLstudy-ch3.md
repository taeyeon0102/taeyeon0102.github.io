## 2. Activation function
- 입력 신호의 총합이 활성화를 일으키는지 정한다.
> **💡 활성화 함수의 필요성**
> 선형 함수만을 이용하면 신경망 층을 깊게 하는 의미가 없어진다. 즉, 여러 층의 선형 함수는 결국 하나의 층으로도 표현 가능하다. 그렇기 때문에 비선형성 부여를 위해서 각 신경망의 뉴런은 가중합 계산과 편향 덧셈 후 활성화 함수를 통과시킨다.

$$a = b+w_1x_1+w_2x_2$$

$$y = h(a)$$

### step function

$$h(x) = \begin{cases} 0 & (x <= 0) \\ 1 & (x>0) \end{cases}$$

![step 그래프](/assets/img/step-function.png)

### sigmoid function

$$h(x)=\frac{1}{1+exp(-x)}=\frac{1}{1+e^{-x}}$$

![sigmoid 함수](/assets/img/sigmoid-function.png)

### sigmoid vs step

- **공통점**: 입력이 작을 때는 0에 가깝고 입력이 커지면 1에 가까워지는 **비선형 함수**이다. 모든 출력값은 0과 1사이에 대응된다.

- **차이점**: `sigmoid`함수는 매끄럽고 연속된 실수를 돌려주는 반면에 `step`함수는 0과 1 중 하나의 값만 돌려준다.

### ReLU 함수
오래전부터 신경망 분야에서 `sigmoid`함수를 사용해왔지만 최근에는 `ReLU`함수를 주로 이용한다.
 입력이 0을 넘으면 그 입력을 그대로 출력하고, 0 이하이면 0을 출력한다.

$$
h(x)=\begin{cases} x & (x>0) \\ 0 &(x<=0) \end{cases}
$$

![ReLU 함수](/assets/img/ReLU-function.png)

## 3. 다차원 배열의 연산
신경망의 계산은 넘파이(Numpy)의 다차원 배열 행렬곱 연산으로 효율적으로 처리할 수 있다.
- 행렬의 곱셈(`np.dot`)을 계산할 때는 **두 행렬의 대응하는 차원의 원소 수**를 일치시켜야 한다.
- $n \times m$과 $a \times b$인 행렬을 곱한다고 할 때, $m = a$이어야 연산이 성립한다.

## 4. 3층 신경망 구현
3층으로 이루어진 순방향 처리를 구현함.

![뉴런](/assets/img/Neurun.png)
*※ 직접 도식화한 자료입니다.*

- **신호 전달의 간소화:** 각 뉴런에서 수행되는 계산은 **$A=XW+B$**라는 행렬 곱 형태로 간소화할 수 있다.
- **출력층 활성화 함수:** 은닉층과 달리 출력층의 활성화 함수는 풀고자 하는 문제의 성질(회귀, 분류 등)에 따라 다르게 설정한다.

### 뉴런 표기법

$$w_{12}^{(1)}$$

> - (1): 1층의 가중치
> - 12: 다음 층의 1번째 뉴런, 앞 층의 2번째 뉴런

### 뉴런의 신호 전달

![3층 신경망](/assets/img/3layerNN.png)
*※ 직접 도식화한 자료입니다.*

$$a_1^{(1)}= w_{11}^{(1)}x_1+w_{12}^{(1)}x_2+b_1^{(1)}$$

이 식을 간소화하면 다음과 같다.

$$A^{(1)}=XW^{(1)}+B^{(1)}$$

$$A^{(1)}=(a_1^{(1)} a_2^{(1)} a_3^{(1)}) \\ X = (x_1 x_2) \\ B^{(1)}=( b_1^{(1)} b_2^{(1)} b_3^{(1)}) \\ W^{(1)}=\begin{pmatrix} w_{11}^{(1)} w_{21}^{(1)} w_{31}^{(1)} \\ w_{12}^{(1)} w_{22}^{(1)} w_{32}^{(1)} \end{pmatrix}$$

### [1] 각 뉴런 정의
```python
# 각 층의 신호 전달 구현
X = np.array([1.0, 0.5])
W1 = np.array([[0.1, 0.3, 0.5], [0.2, 0.4, 0.6]])
B1 = np.array([0.1, 0.2, 0.3])

print(W1.shape) #(2, 3)
print(X.shape) #(2,)
print(B1.shape) #(3,)

## 입력층 -> 1층
A1 = np.dot(X, W1)+B1
Z1 =sigmoid(A1)

print(A1) #[0.3 0.7 1.1]
print(Z1) #[0.57444252 0.66818777 0.75026011]

## 1층 -> 2층
W2 = np.array([[0.1, 0.4], [0.2, 0.5], [0.3, 0.6]])
B2 = np.array([0.1, 0.2])

print(Z1.shape) #(3,)
print(W2.shape) #(3, 2)
print(B2.shape) #(2,)

A2 = np.dot(Z1, W2) + B2
Z2 = sigmoid(A2)

## 2층 -> 출력층
def identity_function(x):
    return x

W3 = np.array([[0.1, 0.3], [0.2, 0.4]])
B3 = np.array([0.1, 0.2])

A3 = np.dot(Z2, W3) + B3
Y = identity_function(A3)

print(Y) #[0.31682708 0.69627909]
```

### [2] 3층 신경망 구현 및 실행

``` python
# 가중치 편향 초기화
def init_network():
    network = {}
    network['W1'] = np.array([[0.1, 0.3, 0.5], [0.2, 0.4, 0.6]])
    network['b1'] = np.array([0.1, 0.2, 0.3])
    network['W2'] = np.array([[0.1, 0.4], [0.2, 0.5], [0.3, 0.6]])
    network['b2'] = np.array([0.1, 0.2])
    network['W3'] = np.array([[0.1, 0.3], [0.2, 0.4]])
    network['b3'] = np.array([0.1, 0.2])

    return network

# 순방향 신호 전달
def forward(network, x):
    W1, W2, W3 = network['W1'], network['W2'], network['W3']
    b1, b2, b3 = network['b1'], network['b2'], network['b3']

    a1 = np.dot(x, W1) + b1
    z1 = sigmoid(a1)
    a2 = np.dot(z1, W2) + b2
    z2 = sigmoid(a2)
    a3 = np.dot(z2, W3) + b3
    y = identity_function(a3)

    return y

# 실행
network = init_network()
x = np.array([1.0, 0.5])
y = forward(network, x)
print(y) #[0.31682708 0.69627909]
```

## 5. 출력층 설계
기계학습의 문제는 **분류(Classification)** 와 **회귀(Regression)** 로 나뉘며, 이에 따라 출력층의 활성화 함수를 선택한다.

- **분류**: 데이터가 어느 클래스에 속하는지 판별 (예: 이미지 숫자 인식) ➔ `Softmax 함수` 사용
- **회귀**: 입력 데이터에서 연속적인 수치를 예측 (예: 집값 예측) ➔ `항등 함수` 사용

### softmax 함수
**소프트맥스 함수의 특징:** 출력 값의 총합이 항상 `1.0`이 되므로, 출력을 **확률**로 해석할 수 있다는 매우 중요한 성질을 가진다.

$$ y_k = \frac{\exp(a_k)}{\sum_{i=1}^{n}\exp(a_i)} $$

**⚠️ 구현 시 주의점:** `지수 함수`($e^x$) 계산 시 값이 너무 커져 발생하는 **오버플로우(Overflow)** 문제를 해결하기 위해 입력 신호 중 최댓값을 빼주는 처리가 필요하다.

``` python
def softmax(a):
    c = np.max(a)        # 배열 요소 중 최댓값
    exp_a = np.exp(a - c) # 오버플로우 대책
    sum_exp_a = np.sum(exp_a)
    y = exp_a / sum_exp_a
    return y
```

## 6. 손글씨 숫자 인식

MNIST 데이터셋을 이용하여 손글씨 숫자를 분류하는 추론 과정(순전파)를 구현한다.

### [1] 데이터 준비 및 신경망 초기화

**정규화(Normalization)**: 픽셀 값을 255로 나누어 0.0~1.0 사이의 값으로 변환한다.

**배치 처리(Batch Processing)**: 데이터를 100장 단위로 묶어(Batch) 행렬곱을 수행하면 연산 속도가 비약적으로 향상된다.

>`load_mnist` 함수: (훈련 이미지, 훈련 레이블), (시험 이미지, 시험 레이블) 형식으로 반환함
>- `normalize`: 입력 이미지 값을 `0-1` 값으로 정규화할지 결정
>  - `flatten`: 입력 이미지를 1차원 배열로 만들지 결정
>  - `one_hot_label`: `one-hot-encoding` 형태로 저장할지 결정

```python
import sys, os
sys.path.append(os.pardir)
import numpy as np
from dataset.mnist import load_mnist
from PIL import Image
import pickle

def img_show(img):
    pil_img = Image.fromarray(np.uint8(img))
    pil_img.show()

(x_train, t_train), (x_test, t_test) = \
    load_mnist(flatten=True, normalize=False)
# 전처리: 정규화

img = x_train[0]
label = t_train[0]
print(label)

print(img.shape) #(784,) 1차원으로 펼쳤기 때문
img = img.reshape(28, 28)  #다시 28*28 이미지로 만듦
print(img.shape)

img_show(img)

# 데이터 가져오기 (정규화 적용, 평탄화 적용)
def get_data():
    (x_train, t_train), (x_test, t_test) = \
         load_mnist(normalize=True, flatten=True, one_hot_label=False)
    return x_test, t_test

def init_network():
    with open("sample_weight.pkl", 'rb') as f:
        network = pickle.load(f)

    return network

# 신경망 추론 (순전파)
def predict(network, x):
    W1, W2, W3 = network['W1'], network['W2'], network['W3']
    b1, b2, b3 = network['b1'], network['b2'], network['b3']

    a1 = np.dot(x, W1) +b1
    z1 = sigmoid(a1)
    a2 = np.dot(z1, W2) + b2
    z2 = sigmoid(a2)
    a3 = np.dot(z2, W3) + b3
    y = softmax(a3)

    return y
```

### [3] 배치 처리를 적용한 신경망 정확도 평가
입력 데이터의 형태가 `784` $\rightarrow$ `784x50` $\rightarrow$ `50x100` $\rightarrow$ `100x10` $\rightarrow$ `10`의 흐름으로 처리된다.

``` python
x, t = get_data()
network = init_network()

accuracy_cnt = 0

for i in range(len(x)):
    y = predict(network, x[i])
    p = np.argmax(y) #가장 확률이 높은 원소의 인덱스 얻음
    if p == t[i]:  # 해당 인덱스와 정답 레이블이 맞는지 확인 후 카운트
        accuracy_cnt += 1

print("Accuracy:" + str(float(accuracy_cnt / len(x))))

## 데이터 흐름
## x -> W1 -> W2 -> W3 -> y
## 784 -> 784*50 -> 50*100 -> 100*10 ->10

# [4] batch size 구현
x, t = get_data()
network = init_network()

batch_size = 100
accuracy_cnt = 0

# 0부터 x까지 배치 크기 간격으로 반복
for i in range(0, len(x), batch_size):
    x_batch = x[i:i+batch_size]
    y_batch = predict(network, x_batch)

    # 확률이 가장 높은 원소의 인덱스를 배열 형태로 변환 (1차원 기준으로)
    p = np.argmax(y_batch, axis=1)

    # 배치 단위로 정답 개수 누적합
    accuracy_cnt += np.sum(p==t[i:i+batch_size])

print("Accuracy:" + str(float(accuracy_cnt) / len(x)))
```
