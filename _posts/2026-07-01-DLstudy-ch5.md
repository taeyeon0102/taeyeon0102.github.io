# 1. 순전파 (Forward Propagation)

*입력 데이터가 신경망을 통과하며 최종 출력 결과를 만들어내는 과정*


- **왼쪽에서 오른쪽으로 진행:** 계산 그래프의 출발점(입력)부터 종착점(출력) 방향으로 계산 결과를 순서대로 전달한다.
- **국소적 계산 (Local Computation):** 순전파의 핵심은 전체 계산이 아무리 복잡하더라도, 각 노드에서는 오직 자신과 직접 관련된 '단순한 정보(국소적 계산)'만으로 결과를 출력하여 다음 노드로 전달한다는 것이다.
- **`forward()` 메서드:** 파이썬으로 계층(Layer)을 구현할 때 순전파 처리를 담당하는 메서드. 특히 곱셈 계층의 경우, 이후 역전파 계산을 위해 순전파 때 입력받은 값(**`x`**, **`y`**)을 변수에 저장한다.

# 2. 역전파 (Backward Propagation)

*출력에서 발생한 오차(손실)를 바탕으로 각 매개변수(가중치)가 오차에 미치는 영향인 미분(기울기) 값을 효율적으로 구하는 과정*

- **오른쪽에서 왼쪽으로 진행:** 순전파와는 반대 방향으로, 즉 종착점(최종 출력)에서 출발점(입력) 방향으로 국소적인 미분 값을 전달한다.
- **연쇄법칙 (Chain Rule):** 역전파가 작동하는 근본적인 원리로, '합성 함수의 미분은 합성 함수를 구성하는 각 함수의 미분의 곱으로 나타낼 수 있다'는 성질이다.
    - 역전파의 계산 절차는 상류(오른쪽)에서 전달받은 미분 값에 현재 노드의 **'국소적 미분(편미분)'을 곱한 후** 다음 노드(왼쪽)로 전달하는 방식으로 이루어진다.
- **`backward()` 메서드:** 계층 구현 시 역전파 처리를 담당하는 메서드로, 상류에서 내려온 미분(**`dout`**)에 각 계층에 맞는 국소적 미분을 곱해 하류로 보낸다.

# 3. 등장 배경과 필요성

**기존 '수치 미분' 방식의 비효율성 극복:** 신경망 학습에서 가중치 매개변수의 기울기를 구하기 위해 기존에 사용하던 수치 미분 방식은 구현이 쉽다는 장점이 있지만, 매개변수마다 일일이 미분을 수행해야 하므로 **계산에 시간이 너무 오래 걸린다는 치명적인 단점**이 있다.

**빠르고 효율적인 기울기(미분) 계산:** 이러한 수치 미분의 느린 속도 문제를 해결하기 위해 등장한 것이 오차역전파법으로, **계산 그래프의 연쇄 법칙을 활용해 역방향으로 국소적 미분을 전달**함으로써 **수많은 매개변수의 기울기를 매우 효율적이고 빠르게 계산**할 수 있다.

# 4. 활성화 함수 계층 구현

## 1) ReLU

![relu-cg](/assets/img/relu-cg.png)

> **계산 그래프 (Computational Graph)**: 계산 과정을 노드(node)와 에지(edge)로 이루어진 그래프

### 순전파 (Forward Propagation): 조건부 출력
        
$$y = \begin{cases} x & (x > 0) \\ 0 & (x \le 0) \end{cases}$$
        
> 입력값($x$)이 0을 넘으면 그 입력을 그대로 다음 노드로 출력하고, 0 이하이면 0을 출력한다.

### 역전파 (Backward Propagation): 신호 전달/차단

$$\frac{\partial y}{\partial x} = \begin{cases} 1 & (x > 0) \\ 0 & (x \le 0) \end{cases}$$
        
> 순전파 때의 입력 $x$가 0보다 컸다면 상류에서 전파된 미분값을 **여과 없이 그대로 하류로 흘려보내고**, $x$가 0 이하였다면 하류로 보내는 **신호를 차단(0을 출력)** 한다.

### 코드 구현

``` python
class Relu:
    def __init__(self):
        self.mask = None         # T/F로 이루어진 넘파이 배열

    def forward(self, x):
        self.mask = (x <= 0)     # 입력이 0 이하이면 True, 0보다 크면 False
        out = x.copy()
        out[self.mask] = 0

        return out

    def backward(self, dout):
        dout[self.mask] = 0
        dx = dout

        return dx
````

> #### 코드 구현의 핵심, 'mask 인스턴스 변수'
> 이 계층을 코드로 구현할 때는 **mask라는 인스턴스 변수**를 활용한다. 순전파 시 입력 $x$ 배열에서 원소 값이 0 이하인 위치를 `True`로 기록해 두고, 역전파 때 이 `mask`를 사용하여 값이 `True`인 곳의 상류 미분값(`dout`)을 0으로 강제 설정하여 신호 차단을 효율적으로 구현한다.

## 2) Sigmoid

![sigmoid-cg](/assets/img/sigmoid-cg.png)

> 시그모이드 함수는 $y=\frac{1}{1+exp(−x)}$ 로 정의되며, 이를 계산 그래프로 나타내면 '×' (−1 곱하기), 'exp', '+' (1 더하기), '/' (역수)라는 총 4가지 노드의 순차적인 흐름을 가진다.

### 역전파 1단계(’/’노드)
'/' 노드($y = \frac{1}{x}$)를 미분하면 $−y^2$이 되므로, 상류에서 흘러온 미분값($\frac{∂L}{∂y}$)에 $−y^2$을 곱해 $- \frac{∂L}{∂y}$을 전달한다.

### 역전파 2단계 (’+' 노드)
 덧셈 노드이므로 상류의 값을 여과 없이 하류로 그대로 흘려보낸다.

### 역전파 3단계 ('exp' 노드)
 'exp' 노드($y=exp(x)$)의 미분은 $exp(x)$이므로 상류의 값에 순전파 때의 입력인 $exp(−x)$를 곱한다.

### 역전파 4단계 ('**×**' 노드)
  '×' 노드에서는 순전파 때 서로 바꾼 값인 −1을 곱해주어 마이너스 기호가 상쇄된다. 이를 모두 거치면 역전파 식은 $\frac{\partial L}{\partial y} y^2exp(−x)$로 도출된다.

![sigmoid-simple-cg](/assets/img/sigmoid-simple-cg.png)

$$
\begin{align*}\frac{\partial L}{\partial y} y^2 \exp(-x) &= \frac{\partial L}{\partial y} \frac{1}{(1 + \exp(-x))^2} \exp(-x) \\&= \frac{\partial L}{\partial y} \frac{1}{1 + \exp(-x)} \frac{\exp(-x)}{1 + \exp(-x)} \\&= \frac{\partial L}{\partial y} y(1 - y)\end{align*}
$$

### 최종 도출 식의 간소화
 앞에서 구한 $\frac{∂L}{∂y} y^2exp(−x)$ 식은, 시그모이드 함수의 원래 성질인 $y=\frac{1}{1+exp(−x)}$를 대입하여 수식을 정리하면 최종적으로 $\frac{\partial L}{\partial y}y(1−y)$라는 아주 깔끔한 형태로 정리된다.

### 코드 구현
``` python
class Sigmoid:
    def __init__(self):
        self.out = None

    def forward(self, x):
        out = sigmoid(x)
        self.out = out
        return out

    def backward(self, dout):
        dx = dout * (1.0 - self.out) * self.out
        # 출력으로 한번에 계산

        return dx
```

# 5. Affine/Softhmax 계층 구현

## 1) Affine

**Affine 계층 구현의 필요성** 

신경망의 순전파에서는 가중치 신호의 총합을 계산하기 위해 행렬의 곱 연산을 수행하는데, 기하학에서는 이러한 변환 처리를 **어파인 변환(Affine transformation)** 이라고 부른다. 이를 'Affine 계층'이라는 하나의 노드(클래스)로 모듈화하여 구현하면, 복잡한 다차원 배열의 행렬 계산을 수식 하나로 단순화하여 신경망의 학습과 추론을 매우 효율적으로 수행할 수 있기 때문에 필요하다.

### 순전파(Forward Propagation) 흐름

![affine 순전파 cg](/assets/img/affine-f-cg.png)

**행렬의 곱 (어파인 변환):** 다차원 배열로 입력된 데이터 **X**와 가중치 매개변수 **W**의 형상(Shape)을 일치시킨 후, 두 배열의 행렬 곱(**`np.dot(X, W)`**)을 수행한다.

**편향 덧셈:** 행렬의 곱으로 도출된 결과에 편향 **B**를 더하여 최종 출력값인 **Y**=**X**⋅**W**+**B**를 계산하고 이를 하류 노드로 전달한다.

### 역전파(Backward Propagation) 흐름

![affine 역전파 cg](/assets/img/affine-b-cg.png)

**전치행렬(Transposed Matrix)을 활용한 기울기 산출:** 행렬을 사용한 역전파를 수행할 때는 형상을 맞추기 위해 행렬의 원소 위치를 바꾼 전치행렬($W^T,X^T$)을 사용한다. 상류에서 넘어온 미분값($\frac{∂L}{∂Y}$)을 바탕으로, 입력 데이터의 기울기는 $\frac{∂L}{∂X}=\frac{∂L}{∂Y}⋅W^T$로 구하고, 가중치의 기울기는 $\frac{∂L}{∂W} = X^T \cdot \frac{∂L}{∂X}$의 수식을 통해 구한다.

**0번째 축(axis=0) 기준의 편향 기울기 합산:** N개의 데이터 묶음(미니배치)을 처리할 때, 상류에서 전달된 편향의 역전파 값($\frac{∂L}{∂Y}$)은 각 데이터의 미분값이 모인 형태가 된다. 따라서 편향의 기울기 ($\frac{∂L}{∂B}$)를 구하기 위해서는 이 미분값들을 0번째 축(데이터를 단위로 한 축, 즉 열 방향)을 기준으로 총합을 구해야 한다.(**`np.sum(dY, axis=0)`**).

### 코드 구현
``` python
class Affine:
    def __init__(self, W, b):
        self.W = W
        self.b = b

        self.x = None
        self.original_x_shape = None
        # 가중치와 편향 매개변수의 미분
        self.dW = None
        self.db = None

    def forward(self, x):
        # 텐서 대응
        self.original_x_shape = x.shape
        x = x.reshape(x.shape[0], -1)              # 평탄화 (데이터의 개수는 유지하면서 나머지는 1차원으로 펴줌)
        self.x = x

        out = np.dot(self.x, self.W) + self.b      # 행렬곱 계산 후 편향 값을 더하여 출력

        return out

    def backward(self, dout):
        dx = np.dot(dout, self.W.T)                # 입력 x 기울기
        self.dW = np.dot(self.x.T, dout)           # 가중치 W 기울기
        self.db = np.sum(dout, axis=0)             # 편향 b에 대한 기울기 (미분값의 합)

        dx = dx.reshape(*self.original_x_shape)  # 입력 데이터 모양으로 변경(텐서 대응)
        return dx
```

## (2) Softmax-with-Loss

![softmax-with-loss-cg](/assets/img/softmax-with-loss-cg.png)

### 순전파 (Forward Propagation) 흐름

- Softmax 계층이 입력된 데이터 값을 정규화하여 확률 형태의 출력값($y$)을 산출한다.
- 이어지는 Cross Entropy Error 계층이 이 Softmax의 출력값($y$)과 실제 정답 레이블($t$)을 전달받아, 최종적인 손실(Loss, $L$) 값을 계산하여 출력한다.

### 역전파 (Backward Propagation) 흐름

- 역전파의 결과는 신경망의 출력값($y$)에서 정답 레이블($t$)을 뺀 ($y−t$)라는 매우 '말끔한' 오차 값으로 도출된다.
- 이렇게 도출된 현재 출력과 정답의 차이(오차)가 그대로 앞 계층으로 전달되어 신경망이 학습 방향을 효율적으로 조정한다.

**교차 엔트로피 오차를 이용하는 이유:**

 소프트맥스 함수의 손실 함수로 교차 엔트로피 오차를 사용하면, 역전파 과정에서 수식이 절묘하게 상쇄되어 신경망의 예측값과 정답의 차이인 ($y−t$) 형태로 오차가 말끔하게 도출되도록 수학적으로 설계되었기 때문이다.

### 코드 구현
``` python
class SoftmaxWithLoss:
    def __init__(self):
        self.loss = None # 손실함수
        self.y = None    # softmax의 출력
        self.t = None    # 정답 레이블(원-핫 인코딩 형태)

    def forward(self, x, t):
        self.t = t
        self.y = softmax(x)
        self.loss = cross_entropy_error(self.y, self.t)

        return self.loss

    def backward(self, dout=1):
        batch_size = self.t.shape[0]
        if self.t.size == self.y.size: # 정답 레이블이 원-핫 인코딩 형태일 때
            dx = (self.y - self.t) / batch_size          # y-t로 깔끔하게 계산! 데이터 1개당 오차이므로 배치사이즈로 나누기
        else:                          # 숫자 인덱스 형태일 때
            dx = self.y.copy()
            dx[np.arange(batch_size), self.t] -= 1
            dx = dx / batch_size

        return dx
```

# 6. 오차역전파법 구현

신경망 학습 구현 절차(4 단계): **미니배치 선별** → **기울기 산출** → **매개변수 갱신** → **반복**

## 1. 계층(Layer)의 모듈화 및 순서 유지
 신경망을 구성하는 각 계층(Affine, ReLU, SoftmaxWithLoss 등)을 **개별 클래스로 모듈화**한다. 이때 `self.layers`라는 **`OrderedDict`**(순서가 있는 딕셔너리)를 사용하여 신경망에 추가된 계층을 **순서대로 보관**한다.

## 2. 순전파 (Forward Propagation) 처리
데이터 예측이나 손실을 구할 때는 `predict()`를 이용하여 **`OrderedDict`**에 저장된 계층들을 앞에서부터 순서대로 꺼내어 각 계층의 **`forward()`** 메서드를 연달아 호출한다. 이 때, 한 계층의 `forward()` 출력이 다음 계층의 입력으로 전달된다.

## 3. 역전파 (Backward Propagation) 처리
가중치 매개변수의 기울기를 구할 때는 `gradient()를 이용하여 `**`layers.reverse()`**를 통해 딕셔너리에 저장된 **계층의 순서를 반대로 뒤집는다**. 그 다음 역순으로 각 계층의 **`backward()`** 메서드를 호출하면, 미분값이 효율적으로 앞 계층으로 연쇄 전달되며 모든 매개변수의 기울기를 구할 수 있다.

### 오차역전파를 적용한 2층 신경망 구현
``` python
class TwoLayerNet:

    def __init__(self, input_size, hidden_size, output_size, weight_init_std = 0.01):
        # 가중치 초기화
        self.params = {}
        self.params['W1'] = weight_init_std * np.random.randn(input_size, hidden_size)
        self.params['b1'] = np.zeros(hidden_size)
        self.params['W2'] = weight_init_std * np.random.randn(hidden_size, output_size)
        self.params['b2'] = np.zeros(output_size)

        # 계층 생성
        self.layers = OrderedDict()
        self.layers['Affine1'] = Affine(self.params['W1'], self.params['b1'])
        self.layers['Relu1'] = Relu()
        self.layers['Affine2'] = Affine(self.params['W2'], self.params['b2'])

        self.lastLayer = SoftmaxWithLoss()

    def predict(self, x):
        for layer in self.layers.values():
            x = layer.forward(x)

        return x

    # x : 입력 데이터, t : 정답 레이블
    def loss(self, x, t):
        y = self.predict(x)
        return self.lastLayer.forward(y, t)

    def accuracy(self, x, t):
        y = self.predict(x)
        y = np.argmax(y, axis=1)
        if t.ndim != 1 : t = np.argmax(t, axis=1)

        accuracy = np.sum(y == t) / float(x.shape[0])
        return accuracy

    # x : 입력 데이터, t : 정답 레이블
    def numerical_gradient(self, x, t):
        loss_W = lambda W: self.loss(x, t)

        grads = {}
        grads['W1'] = numerical_gradient(loss_W, self.params['W1'])
        grads['b1'] = numerical_gradient(loss_W, self.params['b1'])
        grads['W2'] = numerical_gradient(loss_W, self.params['W2'])
        grads['b2'] = numerical_gradient(loss_W, self.params['b2'])

        return grads

    def gradient(self, x, t):
        # forward
        self.loss(x, t)

        # backward
        dout = 1
        dout = self.lastLayer.backward(dout)

        layers = list(self.layers.values())
        layers.reverse()
        for layer in layers:
            dout = layer.backward(dout)

        # 결과 저장
        grads = {}
        grads['W1'], grads['b1'] = self.layers['Affine1'].dW, self.layers['Affine1'].db
        grads['W2'], grads['b2'] = self.layers['Affine2'].dW, self.layers['Affine2'].db

        return grads
```

### 기울기 확인(Gradient Check)
구현이 단순하지만 속도가 느린 **수치 미분**의 결과와, 속도가 빠르지만 구현이 복잡해 실수하기 쉬운 **오차역전파법**의 결과를 비교하여 두 방식에서 구한 기울기가 거의 일치하는지 확인한다. 이를 통해 복잡한 오차역전파법 코드가 버그 없이 **정확하게 구현되었는지 검증**할 수 있다.
